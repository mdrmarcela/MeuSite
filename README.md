## Projetos apresentados

Alguns dos projetos disponíveis no portfólio:

* **Sistema de Resenhas** — aplicação Full Stack utilizando React, Node.js, Express, MySQL, API REST e autenticação JWT.
* **Broker Pub/Sub** — sistema inspirado no modelo MQTT, desenvolvido em Python utilizando sockets TCP, arquitetura Publisher/Subscriber e criptografia.
* **Compilador com ANTLR** — projeto envolvendo definição de gramática, análise léxica e análise sintática.
* **Algoritmo Genético** — solução de otimização aplicada à logística e distribuição de produtos.
* **New Bank** — sistema bancário com interface gráfica, múltiplos idiomas e persistência de dados.
* **Rede Neural** — projeto de Machine Learning desenvolvido para um desafio na plataforma Kaggle.

## Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/mdrmarcela/MeuSite.git
```

Entre na pasta do projeto:

```bash
cd MeuSite
```

Depois, abra o arquivo:

```text
index.html
```

diretamente no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code:

1. Abra o projeto no VS Code.
2. Abra o arquivo `index.html`.
3. Clique com o botão direito.
4. Selecione **Open with Live Server**.
